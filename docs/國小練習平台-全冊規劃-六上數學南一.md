## 4. 全冊共通出題約束

沿用單元一規格 §2（題規、提示、EXP）和 §5（數字範圍、干擾項、詳解、題幹長度），再加上：

1. **原創**：題目、數字、情境自己編。課本的例題情境（例如匯率、英里、火車座位）可以參考題型，但要換成自己的情境和數字。
2. **課綱「不評量」的一律不出題**（教師用書明寫）：
   - 有餘數的分數除法（2-4）：「僅進行探索活動……教師請勿評量」。
   - 有餘數的小數除法（3-2）：「視此為探索活動，不予評量」。
   - 不規則圖形面積的點算估算（4-3）：「可用活動說明……但不評量」。
3. **答案寫最簡**：分數答案一律最簡分數；干擾項不能放和正解等值的寫法（例如正解 3/4，干擾項不能是 6/8），不然等於有兩個正解。
4. **提示三段對應教師用書的「引導題意理解三步驟」**：第 1 段「讀題」（題目在問什麼、線索在哪裡）→ 第 2 段「概念」（要用什麼數學概念或公式）→ 第 3 段「解題」（列式差一步）。這和單元一規格 §2 的漸進原則一致，情境題特別適用。
5. **名詞照南一**：最簡分數、圓周、圓周長、圓周率、直徑、半徑、圓心、比、前項、後項、比值、相等的比、最簡單整數比、扇形、圓心角、周角、弧、弧長、秒速、分速、時速、速率、搭配、規律。

## 5. 各關題型分佈與迷思清單（單元二～八）

格式和單元一規格 §3、§4 相同。Q1～Q2 單一概念，Q3～Q5 兩步計算或易錯點，Q6～Q7 素養情境（Q7 有附件）。

### 單元二 分數磨坊（分數的除法）

**教師用書查證（出題約束）**
- 最簡分數＝分子和分母互質、不能再約分；用最大公因數約分；**帶分數的整數部分不用約分**。
- 同分母分數相除，可以看成整數個單位分數相除：分子除以分子。
- 分數除法的計算規則：**把除數的分子、分母顛倒，再和被除數相乘**；帶分數先化成假分數；計算過程可以先約分。
- 2-5：除數小於 1，商比被除數大；除數等於 1，商等於被除數；除數大於 1，商比被除數小（「每包分裝的公斤數愈小，包數愈多」）。
- 有餘數的分數除法不出題。

**L03 分數除法的計算（2-1～2-3）**

| 題 | 題型 | 要鎖的迷思概念（干擾項來源） |
|---|---|---|
| Q1 | 最簡分數：判斷哪一個是最簡分數，或約成最簡分數 | 只約一次、沒約到底（沒用最大公因數）；以為分子、分母都是奇數就是最簡分數（如 9/15）；帶分數連整數部分一起約 |
| Q2 | 同分母分數的除法（分子÷分子） | 分母也拿來相除；被除數和除數顛倒；答案寫成分母不變的分數 |
| Q3 | 整數除以分數 | 只除以分子；乘了除數卻沒顛倒；以為商一定比被除數小 |
| Q4 | 異分母的真分數除以真分數 | 顛倒的是被除數不是除數；分子除分子、分母除分母，除不盡時亂寫 |
| Q5 | 帶分數的除法（先化成假分數，除數顛倒相乘，可以先約分） | 帶分數沒先化成假分數；整數部分和分數部分分開除；約分時把分子和分子約 |
| Q6 | 素養：生活情境（例如幾公升的果汁每若干公升裝一瓶，剛好裝完，可以裝幾瓶） | 讀錯「誰被分」，被除數和除數放反；用成乘法 |
| Q7 | 素養：附件題（某位同學的計算過程，找出錯在哪一步） | 看不出顛倒錯了數；沒發現帶分數沒先化成假分數 |

**L04 分數除法的應用（2-4～2-5）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 求一份是多少（總量平分成幾份） | 用成乘法；總量和份數位置對調 |
| Q2 | 求 1 單位的價錢或數量（例如幾分之幾公斤賣多少元，1 公斤賣幾元） | 用價錢乘以分數；直覺以為 1 公斤會比較便宜 |
| Q3 | 求幾倍（A 是 B 的幾倍） | 「誰是誰的幾倍」順序反了 |
| Q4 | 未知型（□×3/4＝12、□÷2/3＝6，求□） | 還原時用錯運算 |
| Q5 | 不計算，判斷商比被除數大還是小 | 以為除法結果一定變小；除數小於 1 時判斷反了 |
| Q6 | 素養：比較情境（同樣的總量，每包分裝得愈少，包數愈多） | 直覺「每包愈少、包數也愈少」 |
| Q7 | 素養：附件題（表格：同一個被除數除以不同的分數，哪一個商最大） | 只看除數的分子或分母；表格看錯列 |

### 單元三 小數綠洲（小數的除法）

**教師用書查證**
- 除數是一位小數：除數和被除數**同乘以 10**（小數點同時往右移 1 位）；二位小數同乘以 100。
- **商的小數點要和被除數「新的」小數點對齊**。
- 取概數：**商先算到指定位數的下一位，再四捨五入**（例如求到個位，要算到小數第一位）。
- 3-3：除數小於 1，商比被除數大。
- 有餘數的小數除法不出題。

**L05 小數除法的直式（3-1～3-2）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 整數除以一位小數 | 只移除數的小數點，被除數沒跟著移；被除數沒補 0 |
| Q2 | 整數除以二位小數 | 只乘以 10；被除數少補一個 0 |
| Q3 | 小數除以小數，商是整數 | 移動的位數看被除數，不是看除數 |
| Q4 | 小數除以小數，商是小數 | 商的小數點對齊被除數「原來」的小數點，答案差 10 倍 |
| Q5 | 直式判讀：哪一個直式寫法正確 | 看不出小數點移錯位數 |
| Q6 | 素養：生活情境（例如一卷彩帶每若干公尺剪一段，剛好剪完，能剪幾段） | 被除數和除數放反；公分和公尺沒換 |
| Q7 | 素養：附件題（兩位同學的直式，判斷誰對、錯在哪一步） | 只看答案不看步驟；看不出商的小數點對錯位置 |

**L06 商的大小與取概數（3-3～3-4）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 不計算，判斷商比被除數大還是小 | 以為除法的商一定比較小 |
| Q2 | 同一個被除數除以不同的小數，比較商的大小 | 以為除數愈大，商愈大 |
| Q3 | 對商取概數到整數 | 沒多算一位就四捨五入；做成無條件捨去 |
| Q4 | 對商取概數到指定的小數位數 | 算到指定位就停，沒多算一位 |
| Q5 | 求單位價錢（總價÷數量），比較哪一種比較便宜 | 總價比較低就以為比較便宜 |
| Q6 | 素養：生活情境（看單位價錢決定買哪一種包裝，答案要四捨五入） | 算成「1 元可以買多少」，除數和被除數放反 |
| Q7 | 素養：附件題（三種包裝的容量和價錢表，算出每公升的價錢再比較） | 表格看錯欄；只比總價 |

### 單元四 圓環競技場（圓周長和圓面積）

**教師用書查證**
- 圓周長＝直徑×圓周率；直徑＝圓周長÷圓周率；半徑＝圓周長÷圓周率÷2。計算時圓周率用 **3.14**（π 是國中才用，題目不出現 π）。
- 量出來的比值在 3.13、3.15 左右都可以接受（實測誤差）。
- 圓面積＝半徑×半徑×圓周率；推導：切成很多等份拼成近似長方形，**長＝圓周長的一半、寬＝半徑**。
- 驗算建議：圓面積大約是「半徑×半徑×3」，可以用來判斷答案有沒有算錯（放進詳解的驗算提示）。
- 半徑變成 a 倍：圓周長變 a 倍，圓面積變 a×a 倍。
- 不規則圖形的點算估算不出題。

**L07 圓周長和圓周率（4-1～4-2）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 圓周率的意義：任何圓的圓周長÷直徑都大約是 3.14 | 以為大圓的圓周率比較大；用半徑去除 |
| Q2 | 已知直徑求圓周長 | 直徑×3.14 又再×2 |
| Q3 | 已知半徑求圓周長 | 忘了×2，直接半徑×3.14 |
| Q4 | 已知圓周長求直徑或半徑 | 用成乘法；求半徑忘了再÷2 |
| Q5 | 兩個圓直徑的倍數就是圓周長的倍數 | 和面積混淆，以為要乘兩次 |
| Q6 | 素養：生活情境（車輪滾一圈前進多遠、繞圓形水池走一圈） | 半徑當直徑；圈數和距離的關係弄反 |
| Q7 | 素養：附件題（量測紀錄表：幾個圓的直徑和圓周長，找出量錯的那一筆） | 表格看錯欄；以為 3.13、3.15 就不是圓周率 |

**L08 圓面積（4-3～4-4）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 圓面積公式的由來（拼成近似長方形，長和寬各是什麼） | 長當成整個圓周長；寬當成直徑 |
| Q2 | 已知半徑求圓面積 | 半徑×2×3.14（和圓周長公式混淆） |
| Q3 | 已知直徑求圓面積 | 直接用直徑×直徑×3.14 |
| Q4 | 半徑變 2 倍、3 倍，圓周長和圓面積各變幾倍 | 以為面積也只變 2 倍 |
| Q5 | 複合圖形（正方形裡最大的圓、半圓、圓環） | 正方形邊長當半徑；圓環用半徑相減再算 |
| Q6 | 素養：生活情境（灑水器噴得到的範圍、圓形花圃要鋪多少草皮） | 用成圓周長公式；面積單位寫成公分 |
| Q7 | 素養：附件題（同時列出圓周長和圓面積的表，判斷哪一句說法正確） | 周長和面積的倍數關係弄混 |

### 單元五 天秤宮殿（比和比值）

**教師用書查證**
- 比的記法 a：b，a 是前項、b 是後項；**比值＝前項÷後項**。
- **比和比值不一樣**（比值是一個數）。教師用書說課本刻意不寫成「a：b＝a÷b」，免得學生混淆，**題目和詳解也不要這樣寫**。
- 比值可以用假分數、帶分數或小數表示，**常用假分數**（容易看出前後項的關係）。
- 相等的比：前項和後項**同乘以或同除以一個不等於 0 的數**；用等號記錄（例如 2：3＝4：6）。
- 最簡單整數比：整數、分數、小數的比都要能化成最簡單整數比（先化成整數再約分，或先算比值再約分）。

**L09 比和比值（5-1～5-2）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 用比表示兩個數量的關係 | 前項、後項順序寫反 |
| Q2 | 認識前項和後項 | 前項、後項弄反 |
| Q3 | 求比值 | 用後項÷前項 |
| Q4 | 比和比值的區別 | 以為比就是比值；把比值寫成比的樣子 |
| Q5 | 前後項顛倒後，比值的分子、分母也顛倒；比較兩個比的比值大小 | 只比較前項 |
| Q6 | 素養：生活情境（調飲料：原汁和水的用量比與比值） | 「甲對乙」的順序讀反；拿部分和全部比 |
| Q7 | 素養：附件題（社團人數表，寫出指定兩項的比和比值） | 表格看錯欄；用了全部的人數 |

**L10 相等的比和比的應用（5-3～5-4）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 判斷兩個比是不是相等的比 | 以為前後項同加、同減一個數也相等 |
| Q2 | 前後項同乘或同除，寫出相等的比 | 只乘前項或只乘後項 |
| Q3 | 整數比化成最簡單整數比 | 沒用最大公因數，約不到最簡 |
| Q4 | 分數或小數的比化成最簡單整數比 | 小數比只乘一邊；分數比直接拿分子相比 |
| Q5 | 已知比和其中一個量，求另一個量 | 對應錯項 |
| Q6 | 素養：全部量與部分量（例如男、女生人數比，已知全班人數求男生人數） | 拿前項÷後項去乘全班，沒有用前項÷（前項＋後項） |
| Q7 | 素養：附件題（食譜材料表，放大或縮小份量） | 只放大其中一樣；用加法放大 |

### 單元六 孔雀花園（扇形的周長和面積）

**教師用書查證**
- 圓心角對周角 360° 的比值就是「幾分之幾圓」（例如 45° 是 1/8 圓）。
- 扇形弧長＝圓周長×幾分之幾；**扇形周長＝弧長＋兩條半徑**（半圓：弧長＋直徑）。教師用書特別提醒「最後記得加上兩條半徑，不要遺漏」。
- 扇形面積＝圓面積×幾分之幾。
- 半徑相同時，圓心角變幾倍，弧長和面積也變幾倍。
- 複合圖形：大扇形減小扇形、扇形減三角形、正方形減扇形、轉角處繩子變成不同半徑的扇形。

**L11 扇形的周長和面積（6-1）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 由圓心角判斷是幾分之幾圓 | 用 180 去除；分數倒過來 |
| Q2 | 求扇形的弧長 | 用成圓面積 |
| Q3 | 求扇形的周長 | 忘了加兩條半徑（半圓忘了加直徑） |
| Q4 | 求扇形的面積 | 直徑代入半徑 |
| Q5 | 半徑相同，圓心角變幾倍，弧長和面積變幾倍 | 以為面積要變「幾倍再乘幾倍」 |
| Q6 | 素養：生活情境（摺扇、披薩切片、雨刷掃過的範圍） | 讀錯半徑（拿了總長） |
| Q7 | 素養：附件題（同半徑、不同圓心角的扇形對照表） | 表格判讀錯 |

**L12 複合圖形的面積（6-2）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 繩子綁在牆角，動物能活動的範圍（例如 3/4 圓） | 用了整個圓 |
| Q2 | 大扇形減小扇形 | 半徑先相減再算面積 |
| Q3 | 1/4 圓減掉等腰直角三角形 | 三角形面積忘了÷2 |
| Q4 | 正方形減掉 1/4 圓 | 減成整個圓 |
| Q5 | 長方形減掉兩個半圓（等於減掉一個圓） | 半圓的個數算錯 |
| Q6 | 素養：繩子繞過牆角，半徑變短（不同半徑的扇形相加） | 轉角後半徑沒有變短 |
| Q7 | 素養：附件題（用移補法把塗色部分拼成半圓或正方形） | 拼錯圖形 |

### 單元七 疾風山脈（速率）

**教師用書查證**
- 速率＝距離÷時間；距離＝速率×時間；時間＝距離÷速率。
- 回答速率要寫完整單位：「分速 30 公尺」或「30 公尺／分」。
- 換算：時速÷60＝分速，分速÷60＝秒速（距離單位要一起換，1 公里＝1000 公尺）；比較快慢要先化成同一種單位。
- **平均速率＝總距離÷總時間**。
- 同時同地同方向：距離＝兩者速率差×時間；同時由兩地相向而行：時間＝距離÷兩者速率和。

**L13 秒速、分速、時速（7-1～7-2）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 比較快慢（同距離比時間、同時間比距離） | 花的時間愈長以為愈快 |
| Q2 | 求秒速或分速 | 用時間÷距離 |
| Q3 | 求時速，用正確的速率單位表示 | 秒速、分速、時速的單位配錯 |
| Q4 | 速率固定時，距離和時間的關係 | 公式用反 |
| Q5 | 速率單位換算 | ×60 和÷60 弄反；忘了公里換公尺 |
| Q6 | 素養：比較不同單位的速率（先化成同一種單位） | 沒換單位就直接比數字 |
| Q7 | 素養：附件題（距離和時間對照表，觀察倍數關係） | 表格看錯欄 |

**L14 速率的應用（7-3）**

| 題 | 題型 | 要鎖的迷思概念 |
|---|---|---|
| Q1 | 已知距離和速率求時間（含分鐘、小時換算） | 分鐘和小時沒換 |
| Q2 | 已知速率和時間求距離 | 速率和時間的單位不一致 |
| Q3 | 平均速率 | 兩段速率相加再÷2 |
| Q4 | 同時同地同方向，求一段時間後相差多遠 | 用成速率和 |
| Q5 | 同時由兩地相向而行，求多久相遇 | 用成速率差 |
| Q6 | 素養：行程規劃，算出幾時幾分到達 | 把時刻和時間量混在一起 |
| Q7 | 素養：附件題（路線圖或時刻表） | 漏算中途停留的時間 |

### 單元八 規律迷宮（數量關係）

**教師用書查證**
- 8-1：用文字或符號表示和不變、差不變、積不變、商不變的關係式（例如白天＋晚上＝24 小時、年齡差不變）。
- 8-2：分成幾類、只選一樣用加法；每一步都要選用乘法；排數字時十位數字不能是 0。
- 8-3：先把問題簡化找規律，再回到原題（長條排列、列表找規律、看圖找規律、方陣）。

**L16 搭配問題（8-2）**

| Q6 | 素養：生活情境（套餐、路線選擇） | 題目說「只能選一樣」卻用乘法 |
| Q7 | 素養：附件題（菜單或路線圖，有限制條件） | 漏看限制條件（某些組合不行） |
