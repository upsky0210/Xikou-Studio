## 0. 分工與權限（硬性規定）

| 誰 | 做什麼 |
|---|---|
| Codex | 讀教材、寫題目檔、畫題目用的圖、把關卡加進資料檔、跑驗算／組裝／檢查、寫自檢報告 |
| Claude Code | 抽查題目、把書登記到書架、主題地名與 3D 地標、授權標示、瀏覽器試玩、commit 與 push |
| 老師 | 抽驗（草稿標記由老師決定何時拿掉） |

- 工作資料夾：`C:\AI\web-test`。**可以讀全部；只能寫下面這些路徑**（`<id>` 是書的代號）：
  - `drafts/<id>/`（題目檔、抽驗清單、自檢報告、你自己的產生器）
  - `data/<id>.js`（只加 `levels`、用 `tools/assemble.mjs` 填 `q`；不要手改題目）
  - `data/fig/<id>-*.svg` 和 `tools/make-figures-<id>.mjs`（題目用的圖）
- **不可以改**：`js/`、`css/`、`index.html`、`sw.js`、`tools/` 裡其他檔案、別本書的資料檔、`docs/`、`CLAUDE.md`、`README.md`。需要改這些才能完成的事，寫在自檢報告的「需要 Claude Code 處理」。
- 不要 commit、不要 push、不要連網、不要安裝套件。
- `source/`（教師用書）和 `private/`（JDPS 底稿）不上傳，**不要把裡面的內容複製到會上傳的檔案**：題目檔只寫你自己編的題目和「出自課本哪裡」的依據，不貼課本整段原文、不搬習作和備課用書的題目。
- 這兩個資料夾只存在老師的電腦上。開工前先確認 `source/<該科資料夾>` 和 `private/jdps/` 都在；缺檔就停下來回報，不要用記憶或別的版本代替。

## 2. 共同規格（五科都適用）

### 2.1 題目檔

- 位置：`drafts/<id>/<id>-questions-<批次>.json`，JSON 陣列。樣板直接看 `drafts/mn5/mn5-questions-U3.json`。
- 每題的欄位（順序照樣板）：

```json
{
 "id": "L07-Q3",
 "level": "L07",
 "type": "這一題考什麼（十來個字）",
 "stem": "題幹",
 "attachment": null,
 "answer": "正解（文字）",
 "distractors": [
  { "text": "干擾項", "misconception": "選這個的學生是怎麼想錯的" },
  { "text": "干擾項", "misconception": "……" },
  { "text": "干擾項", "misconception": "……" }
 ],
 "hints": ["第 1 段", "第 2 段", "第 3 段"],
 "explanation": "詳解（可用 \\n 換行）",
 "verify": { "kind": "judge", "basis": "依據" },
 "source": "改作自 JDPS-SS（CC BY-NC-SA 4.0）：原題為……"
}
```

- `id` 的 `L07` 對到資料檔的 `<id>-07`。每關固定 7 題，Q1～Q5 概念與基本應用，Q6、Q7 是情境／資料判讀題。
- `source` 只有「題型或情境取自 JDPS」的題目才寫；完全自編的不寫。社會、自然、英語的干擾項另外加 `"trap": "錯誤類型"`（比照 `drafts/sk6-questions-L01-L03.json`）。
- 附件：表格 `{ "t": [[標題列], [資料列]…], "cap": "標題" }`、條列 `{ "list": […], "cap": "標題" }`、短文 `{ "passage": "…" }`、圖 `{ "fig": "data/fig/<id>-07-a.svg", "alt": "給看不到圖的人的完整文字說明", "text": "圖下方的字（可省略）" }`、英語聽力 `{ "listen": "…", "rate": 0.8 }`／`{ "speakOptions": true }`。附件顯示在題幹上面，題幹要寫「上表」「上圖」「上面」。
- 分數寫 `{{3/4}}`、帶分數寫 `{{1 3/8}}`。

### 2.2 品質規則（Claude Code 抽查就是查這些）

1. **前提只來自課本正文**。課本沒教的不出；教師手冊的「補充資料」「教學研究」「備課資料」不能當答案的前提。每題的 `verify.basis` 寫出依據在課本哪一個單元／活動／頁碼。
2. **干擾項是真的迷思**。每個干擾項對應一種學生會犯的錯，`misconception` 寫清楚。不要一眼就能排除的選項（JDPS 常見：「讓法官可以不用上班」「照片」「55 班」）。
3. **選項長度**。正解不可以比最長的干擾項多 4 個字以上；整關「正解是最長選項」不超過 40%（`check-data.mjs` 會印比例，`--long` 列出題目）。JDPS 的社會 60%、國語 55% 都超標，改作時要把干擾項寫到和正解一樣長。
4. **提示三段漸進**。第 1 段指方向或叫學生重讀題目的某個條件；第 2 段給關鍵線索；第 3 段給到「差一步」。**三段都不可以直接寫出答案**（JDPS 有 12～23% 的題目第 3 段就是答案，要重寫）。
5. **詳解要說為什麼**：正解為什麼對，三個干擾項各錯在哪。最後一段依科目不同（見各科章節）。
6. **用語**：題幹和詳解用五年級讀得懂的臺灣正體中文；名詞跟課本一致。
7. **不重複**：同一關的 7 題不要考同一件事；同一本書不要重複用同一組數字或同一個情境。

### 2.3 資料檔

- 新書：照 `data/mn5.js` 寫。開頭註解寫明教材、JDPS 授權（有改作才寫）。`zones` 一個單元一區，**先只寫 `{ "name": "課本單元名", "unit": "課本單元名" }`**，不要寫 `terrain`（主題地名和地標由 Claude Code 加）。
- 每關：`{ "id": "<id>-07", "z": 區的索引, "name": "關卡名", "lesson": "單元三／第七課", "draft": true, "intro": "進關前的一兩句說明", "q": [] }`。全部 `draft: true`。
- `q` 一律用 `node tools/assemble.mjs` 填，不手改。

### 2.4 每一批的流程（實際跑，把輸出貼進自檢報告）

```bash
node tools/verify-answers.mjs drafts/<id>/<這批的題目檔>
node tools/assemble.mjs data/<id>.js <物件名> drafts/<id>/<id>-questions-*.json
node tools/check-data.mjs data/<id>.js <物件名> drafts/<id>/<id>-questions-*.json --long
node tools/review-sheet.mjs drafts/<id>/抽驗清單-<批次>.md drafts/<id>/<這批的題目檔>
```

要看到「發現 0 個問題」和「沒有問題」才算好。

### 2.5 交件（每一批）

放在 `drafts/<id>/`：題目檔、抽驗清單、`自檢報告-<批次>.md`。自檢報告要有：

1. 四個指令的實際輸出。
2. 這一批每一關對應的課本頁碼範圍。
3. 改作自 JDPS 的題號清單、自編的題號清單。
4. 課本有但這一批沒出到的教學目標（如果有，說明原因）。
5. **沒把握的題目**（答案、頁碼、用詞、圖），一題一行寫出疑點。沒有就寫「無」，不要為了看起來完整而省略。
6. `git status --short` 的輸出，確認只動了第 0 節允許的路徑。
7. 需要 Claude Code 處理的事（例如需要新的附件種類、工具有 bug）。

## 6. 國語（ck5）

  - Q1 字形或多音字、Q2 詞義、Q3 本課的語文讀寫重點（句型、標點等）、Q4 修辭或寫作手法、Q6 主旨或寓意；

## 8. 已經踩過的坑（工具和環境）

- **Windows 的 shell 會弄壞中文和引號**。不要用一行指令塞一段程式（`node -e "…"`、`python - <<EOF`）去改含中文的檔案；把程式寫成檔案放在 `drafts/<id>/` 再執行。Python 讀寫檔案一律 `encoding='utf-8'`，要印中文先 `sys.stdout.reconfigure(encoding='utf-8')`。
- **讀課本：先讀 `source/_text/`**。五科課本已逐頁轉成文字檔（每頁開頭「=== 第 N 頁 ===」，頁碼是 PDF 的頁序，不是課本印的頁碼），總表在 `source/_text/_索引.md`。沒有這個資料夾的電腦，在 repo 根目錄跑 `python -I tools/pdf2text.py .`（要先 `pip install pypdfium2`，Codex 不能安裝就回報）。
  - 數學、自然、社會、英語是橫排，文字順序正常。**國語是直排，抽出來的行序常常前後顛倒**（一段話的句子倒著排），讀的時候要自己重組；課文原句、注音、字音字形這類一定要準的內容，把那一頁轉成圖片（pypdfium2）看過再用。
  - 抽出來的文字有些字會缺或變亂碼（注音、特殊符號、部分國字）；看不清楚就轉圖片看。
- **`verify-answers.mjs`**：
  - `expr`／`round` 的 `expected` 一定要出現在正解文字裡（正解是「乙班」這種就改用 `judge` 或 `max`）。
  - `min`／`max` 的鍵名和 `expected` 不可以帶 `{{ }}`，寫純文字（`"5/8 比較大"`）。
  - `gcd`／`lcm` 的 `expected` 也要出現在正解裡。
- **`check-data.mjs`**：干擾項不可以和正解「等值」（`{{9/12}}` 和 `{{3/4}}` 會被擋）。約分題不要拿沒約完的等值分數當干擾項，改問「要同除以多少」或「誰的結果大小不對」。
- **同一張圖給好幾題用**：`fig` 指向同一個檔案，每一題的 `alt` 都要完整寫一次。
- **題目裡的人名**：甲乙丙丁、小安、小平、小真、小晴這類中性的名字；選項是人名時，四個名字長度要一樣。
- **資料檔被 `assemble.mjs` 重寫成 JSON 格式是正常的**，開頭的註解會保留。
