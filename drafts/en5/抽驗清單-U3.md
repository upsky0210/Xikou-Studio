### L09-Q1　文法：would 後的動詞

**題目**：選出正確的答案填入空格：「I would ____ some rice, please.」

**正解**：like

**干擾項**

- likes　←　【第三人稱混淆】把一般現在式常看到的 s 加在 would 後面的動詞上
- liked　←　【動詞形式混淆】把 would 後面的動詞寫成了過去式
- liking　←　【動詞形式混淆】把表示正在進行的動詞形式用在 would 後面

**提示**

1. 先看空格前面是哪一個字。
2. 把這句和課本點餐時的 I'd 開頭相比。
3. I'd 在這裡是 I would 的縮寫，想想後面的動詞需要變化嗎？

**詳解**：正確概念：I'd 是 I would 的縮寫。would 後用 like 的原形，所以填 like。

破誤：「likes」：把一般現在式常看到的 s 加在 would 後面的動詞上；「liked」：把 would 後面的動詞寫成了過去式；「liking」：把表示正在進行的動詞形式用在 would 後面。

### L09-Q2　句型：選疑問詞

**題目**：填入正確的疑問詞。
A: ____ would you like to eat?
B: I'd like some noodles, please.

**正解**：What

**干擾項**

- Where　←　【疑問詞混淆】用了問地點的字，但回答說的是餐點
- When　←　【疑問詞混淆】用了問時間的字，但回答沒有時間
- Who　←　【疑問詞混淆】用了問人的字，但回答沒有提到任何人

**提示**

1. 先看 B 回答的是哪一類資訊。
2. B 告訴對方自己想吃的餐點。

**詳解**：正確概念：B 說自己想吃麵條，因此 A 要用 What 問對方想吃什麼。

破誤：「Where」：用了問地點的字，但回答說的是餐點；「When」：用了問時間的字，但回答沒有時間；「Who」：用了問人的字，但回答沒有提到任何人。

### L09-Q3　句型：問答配對

**題目**：有人問 Isla：「Would you like some soup?」Isla 想婉拒，可以怎麼回答？

**正解**：No, thank you.

**干擾項**

- Yes, please.　←　【簡答不一致】這是在禮貌接受對方提供的湯
- Yes, thank you.　←　【簡答不一致】只注意到 thank you，忽略 Yes 表示接受
- I'd like some, please.　←　【句型混淆】用了禮貌點餐的句子，表達的是想要喝湯

**提示**

1. 先確認 Isla 想接受還是婉拒。

3. 婉拒之後仍可以謝謝對方，檢查開頭和後半是否都符合。

**詳解**：正確概念：No 表示婉拒，thank you 向對方道謝，所以 No, thank you. 符合 Isla 的意思。

破誤：「Yes, please.」：這是在禮貌接受對方提供的湯；「Yes, thank you.」：只注意到 thank you，忽略 Yes 表示接受；「I'd like some, please.」：用了禮貌點餐的句子，表達的是想要喝湯。

### L09-Q4　文法：選出正確的句子

**題目**：下面哪個英文問句寫得完全正確？

**正解**：Would you like some steak?

**干擾項**

- Would you like eat some steak?　←　【句型混淆】在 like 後接 eat 時，漏掉了 to
- What you would like to eat?　←　【句型混淆】把問句的 would 放在 you 後面，沿用了直述句的順序
- Would you like some a steak?　←　【可數與不可數混淆】把 some 和 a 疊在同一個食物名稱之前

**提示**

1. 分別看每句的問句開頭和後面接的字。
2. 問對方時，would 放在 you 前面。
3. 再看 like 後面，直接接食物就可以表達想不想吃。

**詳解**：正確概念：Would you like some steak? 用 Would you like 開頭，後面直接接 some steak。

破誤：「Would you like eat some steak?」：在 like 後接 eat 時，漏掉了 to；「What you would like to eat?」：把問句的 would 放在 you 後面，沿用了直述句的順序；「Would you like some a steak?」：把 some 和 a 疊在同一個食物名稱之前。

### L09-Q6　聽力：聽問句選回答

**附件**
> 【聽力・畫面不顯示】念：「What would you like to eat, Iris?」（語速 0.9）

**題目**：請聽英文問句，選出最合適的回答。

**正解**：I'd like some dumplings, please.

**干擾項**

- Yes, I'd like to eat, thank you.　←　【疑問詞混淆】只表示想吃東西，沒有回答想吃什麼
- Would you like some dumplings?　←　【句型混淆】反過來問別人要不要吃，沒有說自己想吃什麼
- She'd like some dumplings, please.　←　【人稱代名詞混淆】Iris 被直接問到，回答自己想吃的東西時要用 I

**提示**

1. 先聽這個問句是直接問人，還是在談不在場的人。
2. 聽問句開頭，判斷要選餐點，還是只回答要或不要。
3. 直接被問到的人用自己的角度回答，並說出想吃的餐點。

**詳解**：正確概念：問句直接問 Iris 想吃什麼。Iris 要用 I'd like 加上食物回答。

### L10-Q6　閱讀技巧：排序（Sequence）

**附件**
> 【短文】Ava and her sister want to make a fruit bowl. First, they wash the apples and grapes. Next, Ava cuts the apples. Then, her sister puts the apples and grapes in a big bowl. Finally, they put the bowl on the table. Their friends are ready to eat. The fruit looks good!

**題目**：依上面的短文，水果放入碗裡之後，緊接著的下一個步驟是什麼？

**正解**：她們把碗放到桌上。

**干擾項**

- 她們一起洗兩種水果。　←　【順序錯置】跳回 First，選了第一個步驟

- Ava 的姊妹把水果裝進碗。　←　【順序錯置】選到題目指定的步驟本身

**提示**

1. 找出 First、Next 和 Then，順著看每一步。
2. 先定位「水果放入碗裡」是哪一步。
3. 接著往後看，找出 Finally 標示的最後一個步驟。

**詳解**：正確概念：Then 標示把水果放入碗中。接著 Finally 標示最後一個步驟：兩人把碗放上桌。

破誤：「她們一起洗兩種水果。」：跳回 First，選了第一個步驟；「Ava 把蘋果切好。」：看見 Next 就選了，其實那是裝碗前的動作；「Ava 的姊妹把水果裝進碗。」：選到題目指定的步驟本身。
