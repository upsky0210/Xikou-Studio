## L01 1-1 中華民國走向民主的歷程為何？

### L01-Q1　A 概念與史實判別

**題目**：中華民國政府接收臺灣初期，臺灣人民對政府的失望與不滿逐漸加深。下列哪一項是課本提到的原因？

**正解**：部分來臺官員與軍警貪汙、濫用職權

**干擾項**

- 政府立刻宣布全臺實施戒嚴，限制集會　←　【時代錯置】戒嚴是民國38年的事，接收初期（民國34年起）還沒有實施。
- 臺灣人被要求改日本姓名、參拜神社　←　【時代錯置】改日本姓名、參拜神社是日治時期的皇民化措施，不是戰後接收初期。
- 政府開放人民直接選舉總統、副總統　←　【時代錯置】總統直選是民國85年的事，而且是民主的進步，不會造成不滿。

**提示**

1. 先確定時間：題目問的是民國34年接收臺灣的「初期」。
2. 課本列了幾種情況：任用公職的方式、官員與軍警的作為、物資管控。
3. 把每個選項放回年代檢查：戒嚴、皇民化、總統直選各是什麼時候？

**詳解**：正確概念：課本說接收初期，來臺官員優先任用來自中國的人士擔任公職，甚至出現部分官員與軍警貪汙、濫用職權；政府又嚴密管控稻米、糖等物資，造成物資短缺、失業，人民的失望與不滿逐漸加深。破誤：戒嚴在民國38年才實施；改日本姓名、參拜神社屬於日治時期；總統直選在民國85年，三者都和「接收初期」的年代不合。證據提示：回課本第1課「戰後的接收與治理」一段。

**驗證**：概念判斷題，請人工確認：教學篇 1-1「戰後的接收與治理」：優先任用來自中國的人士擔任公職……部分官員與軍警貪汙、濫用職權；嚴密管控稻米、糖等物資

### L01-Q2　A 概念與史實判別

**題目**：民國38年政府宣布臺灣實施戒嚴。戒嚴時期，人民的哪些自由受到嚴格限制？

**正解**：言論、出版、集會和遊行等自由

**干擾項**

- 受國民教育、納稅和服兵役　←　【權利義務混淆】這些是憲法規定的義務，不是戒嚴所限制的自由，把權利和義務混在一起。
- 選擇職業、搬家和出國旅行　←　【現代觀念直套】課本強調的限制是言論、出版、集會遊行；這個選項是用自己的想像替代課本內容。
- 到醫院看病和購買生活用品　←　【現代觀念直套】戒嚴限制的是表達意見與聚集的自由，不是看病、買東西等日常生活。

**提示**

1. 戒嚴的目的是什麼？課本說是為了防止中國共產黨潛入影響人民。
2. 想想看：政府怕的是人民「說了什麼、寫了什麼、聚在一起做什麼」。
3. 課本列出四種被限制的自由，還提到有些歌曲、書籍被查禁。

**詳解**：正確概念：戒嚴時期，政府為了防止中國共產黨潛入臺灣影響人民，嚴格限制人民言論、出版、集會和遊行等自由，連部分歌曲、書籍也遭到查禁。破誤：受國民教育、納稅、服兵役是憲法規定的義務，不是被戒嚴限制的自由；「選擇職業、出國旅行」和「看病、買東西」不是課本所說的限制重點。證據提示：回課本第1課「戒嚴時期政府的管制與人民爭取民主自由」一段。

**驗證**：概念判斷題，請人工確認：教學篇 1-1「戒嚴時期政府的管制……」：嚴格限制人民言論、出版、集會和遊行等自由，甚至有些歌曲、書籍也遭到查禁

**提示**

1. 先抓兩個線索：年代（民國36年）和起因（查緝私菸）。

**詳解**：正確概念：民國36年政府查緝私菸處理不當，引發示威抗議，爆發二二八事件；人民提出改革要求，政府不但沒有採納，反而以武力鎮壓。破誤：美麗島事件在民國68年，起因是雜誌社舉辦世界人權日遊行；解除戒嚴在民國76年；政府遷臺在民國38年底，原因是作戰失利。三者年代和成因都對不上。證據提示：回課本第1課「二二八事件的發生」一段，以及「戰後臺灣民主發展大事記」。

### L01-Q4　D 因果推論

**題目**：二二八事件後，臺灣的政治發展受到不良影響。依照課本的說法，最主要的原因是什麼？

**正解**：許多人民因為恐懼而選擇遠離政治

**干擾項**

- 人民忙著工作，對政治沒有興趣　←　【因果倒置或單因化】把原因單純化成「沒興趣」，忽略了事件造成的恐懼。
- 政府很快採納了人民的改革要求　←　【因果倒置或單因化】和課本相反：政府沒有採納改革要求，反而武力鎮壓。
- 臺灣人民立刻選出新的總統　←　【時代錯置】人民直選總統要到民國85年才實現。

**提示**

1. 先回想事件的經過：人民提出改革要求後，政府怎麼處理？
2. 許多民眾傷亡，社會著名人士也遭到迫害。目睹這些事的人，心裡會有什麼感受？
3. 課本用了「恐懼」這個詞，後面接的是什麼行動？

**詳解**：正確概念：二二八事件中，政府以武力鎮壓，許多民眾傷亡。事件之後，許多臺灣人民因為恐懼而選擇遠離政治，對臺灣的政治發展造成不良影響。破誤：「對政治沒興趣」把結果的原因簡化掉了；政府並沒有採納改革要求；總統直選是民國85年的事，和事件後的情況年代不合。證據提示：回課本第1課「二二八事件的發生」一段的最後一句。

**驗證**：概念判斷題，請人工確認：教學篇 1-1：「在這次事件後，許多臺灣人民因為恐懼而選擇遠離政治，對臺灣的政治發展造成不良影響。」

## L02 1-2 臺灣人民有哪些權利和義務？

### L02-Q1　A 概念與史實判別

**題目**：中華民國憲法規定人民應盡的義務，是下列哪一組？

**正解**：納稅、服兵役、受國民教育

**干擾項**

- 納稅、服兵役、參加選舉　←　【權利義務混淆】參加選舉屬於參政權，是權利，不是憲法規定的義務。
- 服兵役、信仰宗教、受國民教育　←　【權利義務混淆】信仰宗教屬於自由權，是權利，不是義務。
- 納稅、集會結社、受國民教育　←　【權利義務混淆】集會結社屬於自由權，是權利，不是義務。

**提示**

1. 先分清楚：權利是可以享有的，義務是應該盡到的責任。
2. 選舉、信仰宗教、集會結社，是我們「可以做」的，還是「必須做」的？
3. 課本說的三項義務裡，有一項同時也是權利。

**詳解**：正確概念：中華民國憲法保障人民平等、自由和參與政治等權利，也規定人民應盡納稅、服兵役、受國民教育的義務；其中受國民教育既是權利也是義務。破誤：參加選舉屬於參政權；信仰宗教、集會結社屬於自由權，都是權利，不是義務。證據提示：回課本第2課開頭，以及「人民有納稅的義務……」各段。

**驗證**：概念判斷題，請人工確認：教學篇 1-2：中華民國憲法保障人民的基本權利，包括平等、自由和參與政治等權利，人民也應該盡到納稅、服兵役、受國民教育的義務

### L02-Q2　A 概念與史實判別

**題目**：政府規定一定規模以上的機關與機構，必須僱用一定比率的身心障礙者員工。這項規定主要在保障人民的哪一種權利？

**正解**：平等權

**干擾項**

- 自由權　←　【權利義務混淆】自由權是不受非法干涉的自由；這項規定是在保障弱勢有公平的機會。
- 參政權　←　【權利義務混淆】參政權是選舉、罷免、應考試服公職等參與政治的權利，和僱用規定無關。
- 受國民教育的權利　←　【權利義務混淆】受國民教育和就業僱用無關，而且它同時是權利也是義務。

**提示**

1. 課本說平等權是「法律之前，人人平等」。那為什麼可以對身心障礙者有不同的規定？
2. 課本提到：政府為了保障弱勢族群，可以依據法律「合理」進行不同的對待。
3. 這個例子在課本中放在哪一種權利的段落裡？

**詳解**：正確概念：平等權是指法律之前人人平等；同時，政府為了保障弱勢族群，可以依據法律合理進行不同的對待。身心障礙者權益保障法規定定額僱用，就是課本舉的平等權例子。破誤：自由權是不受非法干涉的自由；參政權是參與政治事務的權利；受國民教育和就業僱用無關，這個例子課本明確歸在平等權。證據提示：回課本第2課「政府施政要保障人民的平等權」一段。

## L03 1-3 民主國家政府與人民的關係為何？

### L03-Q1　A 概念與史實判別

**題目**：在民主國家，人民和政府的關係是什麼？

**正解**：人民是國家的主人，用選票選出執政者組織政府

**干擾項**

- 人民和政府互不相干，各自管自己的事　←　【因果倒置或單因化】政府組成的目的就是為人民服務，兩者關係密切。

2. 在民主國家，執政者是怎麼產生的？
3. 政府組成的目的是什麼？為誰服務？

**驗證**：概念判斷題，請人工確認：教學篇 1-3「人民是民主國家的主人」：在民主國家，人民是國家的主人，人民可以用選票選出執政者，由他們組織政府，為民服務

## L08 4-1 工業化與都市化如何影響人們生活？

### L08-Q1　A 概念與史實判別

**題目**：課本說的「工業化」，是指什麼樣的轉變過程？

**正解**：從事工業的人口逐漸超過農業的過程

**干擾項**

- 都市裡的人口愈來愈多、規模擴大的過程　←　【張冠李戴】這是「都市化」的定義，和工業化混淆了。
- 所有農田都必須改成工廠的過程　←　【名詞望文生義】工業化看的是從事工業的人口，不是所有農田都消失。
- 工廠全部從都市搬到鄉村的過程　←　【名詞望文生義】照字面亂猜，課本的定義和工廠搬遷方向無關。

**提示**

**驗證**：概念判斷題，請人工確認：教學篇 4-1：戰後工業發展持續進行，政府將部分土地畫為工業區……從事工業的人口也逐漸超過農業，這個轉變的過程稱為工業化

### L08-Q2　A 概念與史實判別

**題目**：課本說「都市化」是指什麼？

**正解**：人口聚集使生活便利，吸引更多人移入，都市持續擴大

**干擾項**

- 從事工業的人口逐漸超過從事農業的人口　←　【張冠李戴】這是工業化的定義，不是都市化。
- 鄉村的人全部搬走，只剩下都市　←　【名詞望文生義】都市化是都市擴大，不代表鄉村完全消失。
- 都市人口減少，大家紛紛搬回鄉村居住的過程　←　【因果倒置或單因化】方向相反：都市化是人口往都市聚集。

**提示**

**詳解**：正確概念：工廠提供工作機會，使許多鄉村人口遷移到工廠所在地區；當這個地區生活愈來愈方便，就會吸引更多人口移入，都市規模持續擴大，這個過程稱為都市化。破誤：工業人口超過農業是工業化；都市化不代表鄉村消失；人口回流鄉村和都市化方向相反。證據提示：回課本第1課「工業化是都市化的重要動力」一段。

**驗證**：概念判斷題，請人工確認：教學篇 4-1「工業化是都市化的重要動力」：工廠提供工作機會，使許多鄉村人口遷移到工廠所在的地區。當這個地區的生活愈來愈方便，就會吸引更多人口移入，都市的規模也持續擴大，這個過程稱為都市化

### L08-Q4　D 因果推論

**題目**：課本說「工業化是都市化的重要動力」。這句話的因果關係是什麼？

**正解**：工廠帶來工作機會，吸引人口移入，地區漸漸發展成都市

**干擾項**

- 先有了大都市，政府才開始到附近的鄉村蓋工廠　←　【因果倒置或單因化】因果倒置：是工廠吸引人口，才發展成都市。
- 都市化讓工廠全部關閉，人口回到農村　←　【因果倒置或單因化】和課本相反，工業化與都市化是一起推進的。
- 只要蓋了高樓大廈，就一定會有工廠進駐　←　【因果倒置或單因化】單因化又顛倒因果，課本說的起點是工廠提供工作機會。

**提示**

2. 再找「果」：人口移動後，那個地區變成了什麼？
3. 哪一個選項的順序是「工廠→人口→都市」？

**詳解**：正確概念：工廠提供工作機會，使許多鄉村人口遷移到工廠所在的地區；隨著人口聚集，工廠周邊逐漸發展為都市，生活愈方便又吸引更多人移入。所以工業化是都市化的重要動力。破誤：「先有都市才蓋工廠」把因果倒過來；都市化不會讓工廠全部關閉；蓋高樓不是都市化的起點。證據提示：回課本第1課「工業化是都市化的重要動力」一段。

**驗證**：概念判斷題，請人工確認：教學篇 4-1：工業化使鄉村人口大量遷移到工廠所在區域，隨著人口聚集，工廠周邊也逐漸發展為都市

**題目**：面對自然災害與氣候劇烈變化，有些都市開闢「滯洪池」。這項做法最主要的用意是什麼？

**正解**：暫時儲存雨水，與水共生，減少暴雨造成的災害

**干擾項**

- 設立自然保護區，保護珍貴的物種和景觀　←　【張冠李戴】這是另一項永續行動，目的是保護物種與景觀，不是防洪。
- 推動地方創生，吸引青年返鄉就業　←　【張冠李戴】地方創生是活化產業與文化，和防洪無關。
- 把雨水全部快速排進大海　←　【名詞望文生義】課本強調的是儲存與滲透，不只是「排水」。

**提示**

1. 「滯」是停留，「洪」是大水。滯洪池讓大水怎麼樣？
2. 課本說有些地方透過開闢滯洪池，落實什麼概念？
3. 其他選項也都是永續行動，但它們要解決的問題一樣嗎？

**詳解**：正確概念：課本說，面對自然災害及氣候劇烈變化的威脅，都市與鄉村都需要轉型，擁有能承受災害衝擊並快速回復的能力，例如有些地方開闢滯洪池，落實與水共生，避免暴雨造成災害。破誤：自然保護區是保護物種與景觀；地方創生是活化產業；滯洪池重在暫時儲存，不是全部快速排掉。證據提示：回課本第3課談承受災害衝擊的一段。

**驗證**：概念判斷題，請人工確認：教學篇 4-3：面對自然災害及氣候劇烈變化的威脅……例如：有些地方透過開闢滯洪池，落實與水共生，避免暴雨造成災害

### L10-Q4　D 因果推論

**題目**：近年有些鄉村吸引工廠或物流倉儲公司進駐。依照課本，鄉村能吸引這些公司的主要原因是什麼？

**正解**：鄉村可利用的土地範圍比都市廣大

**干擾項**

- 鄉村的人口比都市多很多　←　【因果倒置或單因化】鄉村人口通常較少，吸引企業的是土地條件。
- 鄉村沒有任何交通道路　←　【因果倒置或單因化】和事實相反，倉儲物流需要交通，課本也說交通進步縮短城鄉往返。
- 政府規定工廠只能蓋在鄉村　←　【名詞望文生義】課本沒有這樣的規定，是因為鄉村土地較廣。

**提示**

1. 蓋工廠、倉儲需要什麼？想想它們的面積。
2. 課本比較都市和鄉村時，鄉村有什麼條件比都市多？
3. 這些公司進駐後，對鄉村居民有什麼好處？

**詳解**：正確概念：課本說，鄉村可利用的土地範圍較都市廣大，吸引工廠或物流倉儲等公司進駐，為鄉村居民帶來就業機會，也帶動周邊建設與發展；例如嘉義縣太保市有足夠土地，吸引科技產業設廠，創造青年返鄉就業機會。破誤：鄉村人口較少；倉儲需要交通便利；沒有規定工廠只能蓋在鄉村。證據提示：回課本第3課「互相依賴的都市與鄉村」一段與圖說 1。

**驗證**：概念判斷題，請人工確認：教學篇 4-3：鄉村可利用的土地範圍較都市廣大，吸引工廠或物流倉儲等公司進駐，為鄉村居民帶來就業機會；圖說：嘉義縣太保市有足夠的土地，吸引科技產業在當地設廠

**驗證**：概念判斷題，請人工確認：附表為示意資料，依教學篇 4-3 城鄉問題的討論編寫（鄉村就業機會少、青壯年人口往都市移動；都市人口過度集中、房價上漲、交通壅擠）

### L10-Q6　E 生活情境素養

**題目**：小傑家住在都市，每週都會買鄉村小農種的蔬菜。這個生活習慣最能說明都市與鄉村的什麼關係？

**正解**：都市居民的消費需求，為鄉村產品提供銷售市場

**干擾項**

- 都市和鄉村完全沒有關係，各過各的　←　【因果倒置或單因化】課本說都市與鄉村互相依賴，交流愈來愈頻繁。
- 鄉村居民的糧食和蔬菜都要靠都市提供　←　【張冠李戴】方向相反：糧食主要由鄉村提供給都市。
- 都市居民都應該搬到鄉村自己種菜　←　【因果倒置或單因化】這不是課本對城鄉關係的說明，城鄉是分工合作。

**提示**

1. 蔬菜從哪裡來？買蔬菜的人住在哪裡？
2. 對鄉村小農來說，都市居民的購買代表什麼？
3. 課本說都市與鄉村之間是什麼樣的關係？

**詳解**：正確概念：課本說，隨著交通運輸與通訊科技進步，都市與鄉村之間交流更加頻繁、彼此分工合作；鄉村提供農漁畜牧產品，都市居民的消費需求則為鄉村各項產品提供銷售的市場，形成互利共生。破誤：城鄉不是毫無關係；糧食主要由鄉村供應；城鄉是分工合作，不是都市居民都要搬去種菜。證據提示：回課本第3課「互相依賴的都市與鄉村」一段。

**驗證**：概念判斷題，請人工確認：教學篇 4-3「互相依賴的都市與鄉村」：都市與鄉村之間交流更加頻繁、彼此分工合作，關係也更密切；學習e點通：都市居民的消費需求，則為鄉村各項產品提供了銷售的市場

### L10-Q7　E 生活情境素養

**題目**：班上討論「怎樣才算永續發展」。下列哪一位同學的說法最符合課本？

**正解**：小雯：滿足需求時也保護環境，讓未來的人也能安居

**干擾項**

- 小凱：只要現在的人生活方便，以後再說　←　【因果倒置或單因化】只顧現在、不顧未來，正好和永續的意思相反。
- 小真：為了保護環境，所有開發都應該停止　←　【因果倒置或單因化】課本說要在滿足生活需求的同時保護環境，不是停止一切。
- 小志：永續就是讓都市不斷變大就好　←　【名詞望文生義】把都市擴大誤當永續；課本強調都市和鄉村共同邁向永續。

**提示**

1. 「永續」的「續」是延續，要延續到誰？
2. 課本說人們在滿足生活需求的同時，應該做哪兩件事？
3. 目標是讓「現在與未來」的居民怎麼樣？

**詳解**：正確概念：課本說，都市與鄉村在產業發展及生活型態等方面雖然各不相同，但人們在滿足生活需求的同時，應該共同保護環境、珍惜資源，讓現在與未來的居民能安居樂業，使都市與鄉村共同邁向永續發展。破誤：只顧現在不是永續；停止一切開發無法滿足生活需求；都市擴大不等於永續。證據提示：回課本第3課「互相依賴的都市與鄉村」一段的最後一句。

**驗證**：概念判斷題，請人工確認：教學篇 4-3：「人們在滿足生活需求的同時，應該共同保護環境、珍惜資源，讓現在與未來的居民能安居樂業，使都市與鄉村共同邁向永續發展。」
