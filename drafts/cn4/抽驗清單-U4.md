## L10 第十課 老鼠嫁女兒

### L10-Q1　字音辨析：多音字

**題目**：「最強的女婿」「個性倔強」「強迫別人」裡的「強」，依序怎麼讀？

**正解**：ㄑㄧㄤˊ、ㄐㄧㄤˋ、ㄑㄧㄤˇ

**干擾項**

- ㄑㄧㄤˊ、ㄑㄧㄤˇ、ㄐㄧㄤˋ　←　「最強」讀對了，後面兩個詞的讀音對調了。
- ㄐㄧㄤˋ、ㄑㄧㄤˊ、ㄑㄧㄤˇ　←　把「最強」讀成倔強的ㄐㄧㄤˋ；健壯有力要讀ㄑㄧㄤˊ。
- ㄑㄧㄤˊ、ㄑㄧㄤˊ、ㄑㄧㄤˊ　←　只記得一個讀音；「強」有三種讀法，要看詞語的意思。

**提示**

1. 「強」有三個讀音，先一個詞一個詞想意思。
2. 「最強」是健壯有力；「倔強」是硬不肯低頭；「強迫」是用力逼別人。
3. 「勉強」和「強迫」同一個讀音；「倔強」的讀音和其他兩個都不同，連聲母也不一樣。

**詳解**：正確概念：「強」表示健壯有力、勢力大時讀ㄑㄧㄤˊ，例如最強、強壯；「倔強」讀ㄐㄧㄤˋ；「強迫」是施加壓力使人服從，讀ㄑㄧㄤˇ。

破誤：「ㄑㄧㄤˊ、ㄑㄧㄤˇ、ㄐㄧㄤˋ」：「最強」讀對了，後面兩個詞的讀音對調了。 「ㄐㄧㄤˋ、ㄑㄧㄤˊ、ㄑㄧㄤˇ」：把「最強」讀成倔強的ㄐㄧㄤˋ；健壯有力要讀ㄑㄧㄤˊ。 「ㄑㄧㄤˊ、ㄑㄧㄤˊ、ㄑㄧㄤˊ」：只記得一個讀音；「強」有三種讀法，要看詞語的意思。

回頭讀：第十課語文練習「比一比讀音」。

**驗證**：概念判斷題，請人工確認：課本 p.98「找個最強的女婿」；p.105 語文練習「比一比讀音」：弟弟雖然倔強（ㄐㄧㄤˋ），卻不是強橫（ㄑㄧㄤˊ）無理；與其強迫（ㄑㄧㄤˇ）他接受意見……。已看過原頁圖片。

### L10-Q2　詞義：捨近求遠

**題目**：鼠爸說：「我真是捨近求遠！」「捨近求遠」是什麼意思？

**正解**：放著身邊的不要，跑去遠處找

**干擾項**

- 住在很遠的地方，捨不得回家　←　把「捨」想成捨不得；這裡的「捨」是放下、不要。
- 先去近的地方，再去遠的地方　←　把詞看成走路的順序，沒有讀出「放棄近的」的意思。
- 不怕路途遙遠，努力往前走　←　把它當成稱讚人不怕遠；鼠爸是在後悔自己找錯方向。

**提示**

1. 「捨」在這裡是放下、不要的意思。
2. 鼠爸跑到村外找了太陽、烏雲和大風，最後最強的其實在哪裡？
3. 把「近的」和「遠的」放回故事裡，鼠爸放下了哪一個、去追哪一個？

**詳解**：正確概念：「捨近求遠」是放棄近的而去追求遠的。鼠爸跑到村外找女婿，最後才發現最強的鼠郎就在自己村裡，所以說自己捨近求遠。

破誤：「住在很遠的地方，捨不得回家」：把「捨」想成捨不得；這裡的「捨」是放下、不要。 「先去近的地方，再去遠的地方」：把詞看成走路的順序，沒有讀出「放棄近的」的意思。 「不怕路途遙遠，努力往前走」：把它當成稱讚人不怕遠；鼠爸是在後悔自己找錯方向。

回頭讀：第十課第二幕的最後，鼠郎爬出牆洞的地方。

**驗證**：概念判斷題，請人工確認：課本 p.101 鼠郎爬出牆洞的一段；旁註：捨棄近的而追求遠的。

### L10-Q3　語文練習：既然……就……

**題目**：「既然」後面說已經是事實的原因，「就」後面說接下來的決定。哪一句用得正確？

**正解**：既然你已經答應了，就要說到做到。

**干擾項**

- 既然你已經答應了，可是還沒做到。　←　「既然」要搭「就」，不能接表示轉折的「可是」。
- 即使你已經答應了，就要說到做到。　←　「即使」要搭「也」，而且這裡說的是已經發生的事。
- 既然你已經答應了，所以不用做到。　←　「既然」要搭「就」，而且答應了卻不用做，前後不合理。

**提示**

1. 先看每一句有沒有用「既然」配「就」。
2. 「既然」後面接的是已經發生的事，還是假設的事？
3. 答應了以後，接下來應該怎麼做才合理？

**詳解**：正確概念：「既然……就……」用來連接事情的原因和結果：「既然」說已經是事實的原因，「就」說根據它推出的決定。答應了，就要做到，前後合理。

破誤：「既然你已經答應了，可是還沒做到。」：「既然」要搭「就」，不能接表示轉折的「可是」。 「即使你已經答應了，就要說到做到。」：「即使」要搭「也」，而且這裡說的是已經發生的事。 「既然你已經答應了，所以不用做到。」：「既然」要搭「就」，而且答應了卻不用做，前後不合理。

回頭讀：第十課語文練習「既然……就……」。

**驗證**：概念判斷題，請人工確認：課本 p.103「既然你們兩情相悅，就祝福你們吧！」；p.105 語文練習「既然……就……」：用來連接事情的原因和結果。選項為自編。

### L10-Q4　劇本的寫法

**題目**：劇本裡常有像「（拉著鼠妞往外逃）」這樣放在括號裡的字。它的作用是什麼？

**正解**：說明角色的動作，讓演員知道怎麼演

**干擾項**

- 這是角色要大聲念出來的臺詞　←　括號裡的字不念出來，角色說的話寫在冒號後面。
- 這是旁白要說給觀眾聽的話　←　旁白另外用「旁白：」寫出來，負責交代故事背景。
- 這是作者寫給讀者看的心得感想　←　劇本的括號是給演出的人看的，不是作者的心得。

**提示**

1. 找一找課文裡，角色說的話寫在哪裡？
2. 「旁白：」後面寫的是什麼？括號裡寫的又是什麼？
3. 「拉著」「抹汗」「抬頭看天」這些是說的話，還是做的事？

**詳解**：正確概念：劇本用冒號寫角色的臺詞，用「旁白」交代背景，括號裡則寫角色的動作或表情，讓演員知道該怎麼演。

破誤：「這是角色要大聲念出來的臺詞」：括號裡的字不念出來，角色說的話寫在冒號後面。 「這是旁白要說給觀眾聽的話」：旁白另外用「旁白：」寫出來，負責交代故事背景。 「這是作者寫給讀者看的心得感想」：劇本的括號是給演出的人看的，不是作者的心得。

回頭讀：第十課第一幕，看括號裡寫的是什麼。

**驗證**：概念判斷題，請人工確認：課本 p.97～103 劇本；旁註：時間、地點、角色是劇本特有的寫作形式；旁白負責交代故事背景或敘述；「△」表示畫面說明。課文的括號如（眾鼠舉手喊著）、（抹汗，抬頭看天）。

### L10-Q5　短文閱讀：找出原因

**附件**
> 【短文】鼠爸想替女兒鼠妞找一個最強的丈夫，因為上次招親時，黑貓突然跑出來，把大家都嚇跑了，他希望新女婿能保護女兒。他先去找太陽，太陽說：「烏雲一來，我就只能躲起來。」他去找烏雲，烏雲卻被大風輕輕一吹就推走了。大風說：「我很強，可是碰到牆就過不去。」鼠爸趕緊回村裡問牆，牆正要開口，腳下卻被咬了一口，原來是鼠郎從牆洞裡鑽了出來。鼠爸這才明白，最強的就在身邊。正月初三晚上，鼠妞開開心心的嫁給了鼠郎。

**題目**：根據上面的短文，鼠爸為什麼想找一個最強的女婿？

**正解**：上次招親被黑貓嚇跑，想保護女兒

**干擾項**

- 鼠妞說她只肯嫁給最強的人　←　短文沒有說鼠妞的想法，想找最強女婿的是鼠爸。
- 村裡規定女兒一定要嫁給太陽　←　短文沒有這個規定，太陽只是鼠爸找的第一個對象。
- 鼠爸想讓女兒搬到天上去住　←　鼠爸找太陽是因為覺得它強，不是想讓女兒住到天上。

**提示**

1. 找到短文第一句的「因為」。
2. 上次招親的時候，發生了什麼事？
3. 如果女婿很強，遇到黑貓時可以做什麼？

**詳解**：正確概念：上次招親時黑貓跑出來，把大家嚇跑了，所以鼠爸想找一個最強的女婿，好保護女兒。

回頭讀：第十課第二幕的開頭。

**驗證**：概念判斷題，請人工確認：自編短文首句；對應課本 p.98 第二幕「唉！前幾天那黑貓真是嚇人！看來，我們得找個最強的女婿才行」。

### L10-Q6　主旨與寓意

**題目**：〈老鼠嫁女兒〉最想告訴我們什麼道理？

**正解**：每個人都有自己的長處，不要小看自己

**干擾項**

- 結婚時，一定要找世界上最強的對象　←　鼠爸最後明白不用往外找最強的，故事不是要人這樣做。
- 只要一看到黑貓出現，就要趕快跑才會安全　←　黑貓只是故事的開頭，不是故事要說的道理。
- 太陽是天下最強大、最厲害的東西　←　太陽自己說烏雲一來它就要躲起來，它也有弱點。

**提示**

1. 太陽、烏雲、大風、牆，各被誰勝過？
2. 它們每一個有沒有自己厲害的地方，也有自己的弱點？
3. 鼠爸最後發現，「小看」了誰的本事？

**詳解**：正確概念：太陽、烏雲、大風、牆和老鼠都有厲害的地方，也都有弱點。鼠爸最後發現老鼠也很強，明白每個人都有自己的長處，天生我才必有用。

破誤：「結婚時，一定要找世界上最強的對象」：鼠爸最後明白不用往外找最強的，故事不是要人這樣做。 「只要一看到黑貓出現，就要趕快跑才會安全」：黑貓只是故事的開頭，不是故事要說的道理。 「太陽是天下最強大、最厲害的東西」：太陽自己說烏雲一來它就要躲起來，它也有弱點。

回頭讀：第十課第二幕的最後和第三幕。

**驗證**：概念判斷題，請人工確認：課本 p.96～103 全課；本課主旨：天生我才必有用，每個人都有自己的長處；p.105「讀一讀，想一想」。

### L10-Q7　短文閱讀：整理關係

**附件**
> 【短文】鼠爸想替女兒鼠妞找一個最強的丈夫，因為上次招親時，黑貓突然跑出來，把大家都嚇跑了，他希望新女婿能保護女兒。他先去找太陽，太陽說：「烏雲一來，我就只能躲起來。」他去找烏雲，烏雲卻被大風輕輕一吹就推走了。大風說：「我很強，可是碰到牆就過不去。」鼠爸趕緊回村裡問牆，牆正要開口，腳下卻被咬了一口，原來是鼠郎從牆洞裡鑽了出來。鼠爸這才明白，最強的就在身邊。正月初三晚上，鼠妞開開心心的嫁給了鼠郎。

**題目**：根據上面的短文，哪一組「誰勝過誰」說得對？

**正解**：風能吹走烏雲，牆能擋住風

**干擾項**

- 太陽能趕走烏雲，風能擋住牆　←　短文寫烏雲一來太陽就躲起來，是烏雲勝過太陽；風也擋不住牆。
- 烏雲能擋住牆，老鼠能吹走風　←　短文沒有寫烏雲和牆、老鼠和風的關係。
- 牆能遮住太陽，烏雲能咬穿牆　←　咬穿牆的是老鼠，不是烏雲；短文也沒寫牆遮住太陽。

**提示**

1. 把短文裡鼠爸找的對象依序列出來。
2. 每一個對象都說了自己怕誰，把它們一個一個接起來。
3. 一組裡有兩件事，兩件都要和短文一樣才對。

**詳解**：正確概念：短文寫烏雲擋住太陽、大風吹走烏雲、牆擋住大風、老鼠咬穿牆。只有「風能吹走烏雲，牆能擋住風」兩件事都和短文一樣。

破誤：「太陽能趕走烏雲，風能擋住牆」：短文寫烏雲一來太陽就躲起來，是烏雲勝過太陽；風也擋不住牆。 「烏雲能擋住牆，老鼠能吹走風」：短文沒有寫烏雲和牆、老鼠和風的關係。 「牆能遮住太陽，烏雲能咬穿牆」：咬穿牆的是老鼠，不是烏雲；短文也沒寫牆遮住太陽。

回頭讀：第十課第二幕，看每個角色怎麼說自己的弱點。

**驗證**：概念判斷題，請人工確認：自編短文中段；對應課本 p.98～101 第二幕：太陽→烏雲→大風→牆→老鼠。

## L11 第十一課 豆粥婆婆

### L11-Q1　多義詞：虎口

**題目**：「這段山路又窄又彎，車子一多，簡直就是虎口。」這裡的「虎口」是什麼意思？

**正解**：非常危險的地方

**干擾項**

- 大拇指和食指相連的地方　←　這是「虎口」的另一個意思，用在手上，不合山路的句子。
- 老虎張開的大嘴巴　←　句子在說山路，不是真的有老虎。
- 山洞前面的入口　←　把「口」想成出入口，句子強調的是危險。

**提示**

1. 「虎口」有兩種意思，要看句子在說什麼。
2. 句子說山路「又窄又彎，車子一多」，那會怎樣？
3. 老虎的嘴巴很可怕，把它用在路上，是在比喻什麼？

**詳解**：正確概念：「虎口」本來是老虎的嘴，比喻非常危險的地方；另一個意思是大拇指和食指相連的部位。句子說山路窄又彎、車子多，是比喻危險的地方。

破誤：「大拇指和食指相連的地方」：這是「虎口」的另一個意思，用在手上，不合山路的句子。 「老虎張開的大嘴巴」：句子在說山路，不是真的有老虎。 「山洞前面的入口」：把「口」想成出入口，句子強調的是危險。

回頭讀：第十一課語文練習「虎口」。

**驗證**：概念判斷題，請人工確認：課本 p.113 語文練習「虎口」：1 虎嘴，比喻非常危險的地方；2 大拇指與食指相連的部位；p.107「虎口逃生」、p.110「封住虎口」。例句為自編。

### L11-Q2　詞義：面無血色

**題目**：老虎突然出現在眼前，「嚇得她面無血色」。「面無血色」是什麼意思？

**正解**：嚇得臉色發白

**干擾項**

- 臉上沾滿了紅豆　←　把「血色」想成紅色的東西，其實是說臉色。
- 臉被太陽晒得發紅　←　意思相反；「無血色」是臉上沒有血色、變白了。
- 臉上受傷流了血　←　把「血」當成真的流血，這裡說的是害怕的樣子。

**提示**

1. 「面」是臉，「血色」是臉上紅潤的顏色。
2. 「無血色」是沒有了紅潤的顏色，臉看起來會怎樣？
3. 婆婆看到老虎是什麼心情？人害怕時臉色會怎樣？

**詳解**：正確概念：「面無血色」是臉上沒有血色，形容非常害怕或生病時臉色發白。婆婆突然看到老虎，嚇得臉都白了。

### L11-Q3　語文練習：先……接著……最後……

**題目**：「先……接著……最後……」用來說明事情的先後順序。哪一句用得最合理？

**正解**：我先洗好米，接著加水，最後按下電鍋開關。

**干擾項**

- 我先按下電鍋開關，接著洗好米，最後加水。　←　關聯詞用對了，但米和水還沒放進鍋子就先煮，順序不合理。
- 我先洗好米，最後加水，接著按下電鍋開關。　←　「最後」要放在最後一件事，不能夾在中間。
- 我接著洗好米，先加水，最後按下電鍋開關。　←　「先」要放在第一件事，「接著」放在第二件。

**提示**

1. 先看「先」「接著」「最後」三個詞的位置對不對。
2. 關聯詞排對以後，再想事情的順序合不合理。
3. 煮飯時，米和水沒放進電鍋以前，按下開關有用嗎？

**詳解**：正確概念：「先……接著……最後……」說明動作或事情的先後，順序不可以顛倒。洗米、加水、按下電鍋開關，一定要照這個順序，關聯詞也放對了。

破誤：「我先按下電鍋開關，接著洗好米，最後加水。」：關聯詞用對了，但米和水還沒放進鍋子就先煮，順序不合理。 「我先洗好米，最後加水，接著按下電鍋開關。」：「最後」要放在最後一件事，不能夾在中間。 「我接著洗好米，先加水，最後按下電鍋開關。」：「先」要放在第一件事，「接著」放在第二件。

回頭讀：第十一課語文練習「先……接著……最後……」。

**驗證**：概念判斷題，請人工確認：課本 p.110「栗子先往虎頭敲了一記。接著……最後……」；p.113 語文練習「先……接著……最後……」。選項為自編。

### L12-Q3　語文練習：連接詞改變意思

**題目**：「弟弟打破了杯子，媽媽……」哪一句用「不但……反而……」，寫出讓人意想不到的轉變？

**正解**：媽媽不但沒有罵他，反而關心他有沒有受傷。

**干擾項**

- 媽媽一看見碎片，就生氣的把他狠狠罵了一頓。　←　用「就」接著發生的事，是照常理發展，沒有轉變。
- 媽媽不但罵了他，還要他把碎片掃乾淨。　←　「不但……還……」是同一個方向越來越多，不是轉變。
- 媽媽不但沒有罵他，反而也沒有理他。　←　「也沒有理他」和「沒有罵他」是同一個方向，沒有轉折，用不上「反而」。

**提示**

1. 打破杯子，照常理媽媽會怎樣？
2. 「不但」後面先說沒有發生的事，「反而」後面要接什麼樣的事？
3. 哪一句的結果，和你原本猜的完全相反？

**詳解**：正確概念：「不但……反而……」先從否定的一面說，再往相反的方向推進一步。照常理媽媽會罵人，結果不但沒罵，反而關心他，這就是意想不到的轉變。

回頭讀：第十二課語文練習「找一找：故事大轉彎」。

**驗證**：概念判斷題，請人工確認：課本 p.117 回家路上替地藏戴斗笠的一段；p.121 語文練習「找一找：故事大轉彎」（事件→轉折→結果）。

### L12-Q6　主旨與寓意

**題目**：〈戴斗笠的地藏〉最想告訴我們什麼道理？

**正解**：心存善念、樂於助人，自然會有好結果

**干擾項**

- 做生意要把東西賣便宜，才賣得出去　←　老爺爺的斗笠已經「便宜又耐用」，故事重點不在怎麼做生意。
- 下大雪的時候，最好不要出門賣東西　←　天氣只是故事的背景，不是故事要說的道理。
- 想吃什麼東西，一定要自己去買才行　←　老夫妻的年糕不是自己買的，是做了好事以後得到的。

**提示**

1. 老爺爺自己都很窮了，為什麼還把斗笠給地藏戴？
2. 他替地藏戴上斗笠的時候，有沒有想到會得到回報？
3. 故事最後老夫妻得到了什麼？這和老爺爺做的事有什麼關係？

**詳解**：正確概念：老爺爺雖然貧苦，看到地藏頭上積雪，仍然替祂們戴上斗笠和頭巾，最後得到意想不到的回報。故事告訴我們心存善念、樂於助人，自然能有好的結局。

破誤：「做生意要把東西賣便宜，才賣得出去」：老爺爺的斗笠已經「便宜又耐用」，故事重點不在怎麼做生意。 「下大雪的時候，最好不要出門賣東西」：天氣只是故事的背景，不是故事要說的道理。 「想吃什麼東西，一定要自己去買才行」：老夫妻的年糕不是自己買的，是做了好事以後得到的。

回頭讀：第十二課最後兩段。

**驗證**：概念判斷題，請人工確認：課本 p.114～119 全課；本課主旨：心存善念，樂於助人，自然能夠得到好的結局。

### L12-Q7　短文閱讀：推想

**附件**
> 【短文】日本的深山裡，住著一對貧苦的老夫妻，靠做斗笠過日子。新年前一天，老婆婆說好想吃年糕，老爺爺就背著斗笠下山去賣。雪下得好大，他叫賣了一整天，一頂也沒賣出去。回家路上，他看見路邊六座地藏的頭上積滿了雪，就把斗笠一一替祂們戴上，還少一頂，便解下自己的頭巾，給最小的地藏戴上。老婆婆聽了，不但沒有怪他，反而誇他做了好事。半夜，門外傳來歌聲，老夫妻開門一看，門口堆滿了米、青菜、魚和年糕，遠處有幾個戴斗笠的身影慢慢走遠。

**題目**：根據上面的短文，門口那些米、青菜、魚和年糕，最可能是怎麼來的？

**正解**：地藏為了答謝老爺爺送來的

**干擾項**

- 年糕店老闆後悔了，偷偷送來　←　短文沒有寫年糕店老闆，也沒有線索指向他。
- 老婆婆白天自己下山去買的　←　老夫妻沒有錢，老婆婆也沒有下山。
- 村裡的人來買斗笠時付的錢　←　斗笠一頂也沒賣出去，而且門口是食物不是錢。

**提示**

1. 短文最後一句，老夫妻在遠處看見了什麼？
2. 誰頭上戴著斗笠？
3. 老爺爺先為誰做了好事，誰就可能來謝謝他？

**詳解**：正確概念：遠處有幾個戴斗笠的身影慢慢走遠，而戴著斗笠的正是老爺爺幫助過的地藏，所以可以推想，食物是地藏為了答謝老爺爺送來的。

破誤：「年糕店老闆後悔了，偷偷送來」：短文沒有寫年糕店老闆，也沒有線索指向他。 「老婆婆白天自己下山去買的」：老夫妻沒有錢，老婆婆也沒有下山。 「村裡的人來買斗笠時付的錢」：斗笠一頂也沒賣出去，而且門口是食物不是錢。

回頭讀：第十二課最後一段。

**驗證**：概念判斷題，請人工確認：自編短文末句；對應課本 p.119「老夫妻只見遠處漸漸消失的身影，像極了那些戴斗笠的地藏」。
