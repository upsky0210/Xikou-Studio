## L01 第一課 窗口邊的臺灣欒樹

### L01-Q1　字形辨析

**題目**：哪一組詞語的字都寫對了？

**正解**：一幅風景畫、一簇簇黃花

**干擾項**

- 一副風景畫、一簇簇黃花　←　「副」用在成對、成套的東西，例如一副眼鏡；一張畫要用「幅」。
- 一幅風景畫、一族族黃花　←　「族」用在家族、民族；花一叢一叢聚在一起要用「簇」。
- 一福風景畫、一簇簇黃花　←　「福」是幸福的福，不能當作畫的量詞。

**提示**

1. 先看每個量詞後面接的是什麼東西。
2. 畫是畫在紙或布上的一整張；花是一叢一叢聚在一起的。
3. 「副」常說一副眼鏡、一副手套，這種成對的東西和一張畫一樣嗎？

**詳解**：正確概念：計算圖畫用「幅」，例如一幅畫；很多花聚成一叢用「簇」，例如一簇一簇的黃花。

破誤：「一副風景畫、一簇簇黃花」：「副」用在成對、成套的東西，例如一副眼鏡；一張畫要用「幅」。 「一幅風景畫、一族族黃花」：「族」用在家族、民族；花一叢一叢聚在一起要用「簇」。 「一福風景畫、一簇簇黃花」：「福」是幸福的福，不能當作畫的量詞。

回頭讀：第一課寫秋天的那一段和最後一段，找「簇」和「幅」。

**驗證**：概念判斷題，請人工確認：課本 p.10 寫秋天的一段「開滿一簇一簇的黃花」、p.11 最後一段「像一幅風景畫」；兩字都是本課生字（p.12 加油小站）。

### L01-Q2　詞義：體貼入微

**題目**：課文說冬天的臺灣欒樹「體貼入微，連忙脫去身上的黃葉」。「體貼入微」是什麼意思？

**正解**：照顧別人想得非常細心周到

**干擾項**

- 身體貼著窗戶，靠得很近　←　只看字面的「體」和「貼」，以為是身體貼著東西。
- 葉子很小，要仔細看才看得到　←　把「微」想成很小的東西，忽略這個詞在說對人的關心。
- 動作很慢，一點一點掉葉子　←　把「入微」想成慢慢的、一點一點的動作。

**提示**

1. 先看看臺灣欒樹脫去黃葉以後，是「好讓我們」做什麼？
2. 樹葉掉光，陽光才照得進來，這是在替誰著想？
3. 「入微」是連很細小的地方都想到了，再和「體貼」合起來想。

**詳解**：正確概念：「體貼入微」是對別人的關懷照顧十分細心周到。作者把樹寫成人，好像它知道冬天要讓陽光照進來，所以趕快脫去黃葉。

破誤：「身體貼著窗戶，靠得很近」：只看字面的「體」和「貼」，以為是身體貼著東西。 「葉子很小，要仔細看才看得到」：把「微」想成很小的東西，忽略這個詞在說對人的關心。 「動作很慢，一點一點掉葉子」：把「入微」想成慢慢的、一點一點的動作。

回頭讀：第一課寫冬天的那一段，讀臺灣欒樹做了什麼。

**驗證**：概念判斷題，請人工確認：課本 p.10 寫冬天的一段；旁註：對他人的關懷與照顧，十分細微周到。

### L01-Q3　語文練習：短語

**題目**：「開滿一簇一簇的黃花」是「動作＋一Ａ一Ａ的＋東西」的短語。哪一個也是這樣的寫法？

**正解**：搬來一箱一箱的書

**干擾項**

- 一箱書搬得很辛苦　←　有「一箱」，但沒有重複成「一箱一箱」，順序也不同。
- 搬來很多箱的新書　←　有動作和東西，可是用「很多箱」，沒有「一Ａ一Ａ」。
- 一箱又一箱的書本　←　有重複的量詞，但前面少了動作。

**提示**

1. 把「開滿一簇一簇的黃花」拆成三塊：開滿／一簇一簇的／黃花。
2. 每個選項都照這三塊去對：有沒有動作？量詞有沒有重複？最後是不是東西？
3. 量詞要像「一簇一簇」那樣，同一個詞說兩次，而且前面要先有動作。

**詳解**：正確概念：這種短語是「動作＋一Ａ一Ａ的＋東西」：「搬來」是動作，「一箱一箱的」是重複的量詞，「書」是東西，三塊都有，順序也一樣。

破誤：「一箱書搬得很辛苦」：有「一箱」，但沒有重複成「一箱一箱」，順序也不同。 「搬來很多箱的新書」：有動作和東西，可是用「很多箱」，沒有「一Ａ一Ａ」。 「一箱又一箱的書本」：有重複的量詞，但前面少了動作。

回頭讀：第一課語文練習的第一題，看例句怎麼排。

**驗證**：概念判斷題，請人工確認：課本 p.13 語文練習「開滿一簇一簇的黃花」（動詞＋單位量詞（一Ａ一Ａ）＋的＋名詞）。選項為自編。

### L01-Q4　修辭：找出相似的地方

**題目**：作者說「窗口邊的臺灣欒樹像一幅風景畫」。臺灣欒樹和風景畫相似的地方是什麼？

**正解**：從窗口看出去的樹景，美得像掛著的畫

**干擾項**

- 臺灣欒樹是作者照著風景畫種下的　←　把比喻當成真的事；樹是學校種的，不是照著畫種的。
- 作者在窗邊掛了一幅臺灣欒樹的畫　←　把「像一幅畫」讀成真的掛了一幅畫。
- 臺灣欒樹和畫一樣，一年四季都不會改變　←　畫面不會變，可是課文寫的臺灣欒樹四季都在變。

**提示**

1. 「像」字前面說的是什麼？後面又是什麼？
2. 想一想，從窗口看出去，窗框圍住的是什麼樣子？
3. 課文寫臺灣欒樹四季有不同的顏色，這和一幅美麗的畫有什麼相同之處？

**詳解**：正確概念：作者從窗口看出去，臺灣欒樹被窗框圍著，四季有不同的顏色和樣子，美得就像掛在家裡的一幅風景畫。用「像」把兩樣東西相似的地方連起來，就是譬喻。

破誤：「臺灣欒樹是作者照著風景畫種下的」：把比喻當成真的事；樹是學校種的，不是照著畫種的。 「作者在窗邊掛了一幅臺灣欒樹的畫」：把「像一幅畫」讀成真的掛了一幅畫。 「臺灣欒樹和畫一樣，一年四季都不會改變」：畫面不會變，可是課文寫的臺灣欒樹四季都在變。

回頭讀：第一課最後一段，再看語文練習「找出相似的地方」。

**驗證**：概念判斷題，請人工確認：課本 p.11 最後一段；p.13 語文練習「找出相似的地方」；旁註說明欒樹四季的風貌美化了作者的家。

## L02 第二課 奶奶的排骨粥

### L02-Q1　字形辨析：讀音相同的字

**題目**：「汽」和「氣」讀音一樣。哪一組詞語的字都寫對了？

**正解**：汽水、生氣

**干擾項**

- 氣水、生氣　←　冒泡泡的飲料是「汽水」，用水部的「汽」。
- 汽水、生汽　←　心裡不高興是「生氣」，用「氣」。
- 氣水、生汽　←　兩個字放反了：飲料用「汽」，心情用「氣」。

**提示**

1. 兩個字讀音相同，要靠意思來分。
2. 「汽」是水部，常和水燒開後變成的東西、汽車有關；「氣」常說空氣、心情。
3. 一個詞是喝的飲料，一個詞是心裡的感覺，各配哪一個字？

**詳解**：正確概念：「汽」常用在汽水、汽油、汽車；「氣」常用在空氣、生氣、氣質。這兩個字沒有一定的規則，要多讀多記常用的詞。

破誤：「氣水、生氣」：冒泡泡的飲料是「汽水」，用水部的「汽」。 「汽水、生汽」：心裡不高興是「生氣」，用「氣」。 「氣水、生汽」：兩個字放反了：飲料用「汽」，心情用「氣」。

回頭讀：第二課語文練習「比一比讀音相同的字」。

**驗證**：概念判斷題，請人工確認：課本 p.15 課文開頭「被汽車撞倒」；p.19 語文練習「比一比讀音相同的字」：汽油、汽水、蒸汽機／空氣、生氣、氣質。

### L02-Q2　詞義：入口即化

**題目**：奶奶把粥「煮到入口即化」。「入口即化」是什麼意思？

**正解**：煮得很軟爛，放進嘴裡不必用力咬

**干擾項**

- 粥一倒進碗裡，馬上就變涼了　←　把「化」想成溫度變了；這裡說的是食物軟到化開。
- 粥太燙了，要先放在門口等它變涼　←　把「入口」當成門口；這裡的「口」是嘴巴。
- 粥的味道很淡，吃起來像清水　←　把「化」想成味道變淡，課文說粥的湯底清甜、美味無比。

**提示**

1. 「入口」的「口」，指的是門口還是嘴巴？
2. 作者那時斷了門牙，吃東西有什麼困難？
3. 東西一放進嘴裡就「化」開，表示它煮得怎麼樣？

**詳解**：正確概念：「入口即化」是食物熟透，放進嘴裡就化開，不需要咀嚼。作者斷了門牙、奶奶戴假牙，所以奶奶把粥煮得非常軟爛。

破誤：「粥一倒進碗裡，馬上就變涼了」：把「化」想成溫度變了；這裡說的是食物軟到化開。 「粥太燙了，要先放在門口等它變涼」：把「入口」當成門口；這裡的「口」是嘴巴。 「粥的味道很淡，吃起來像清水」：把「化」想成味道變淡，課文說粥的湯底清甜、美味無比。

回頭讀：第二課奶奶煮排骨粥的那一段。

### L02-Q3　語文練習：即使……也……

**題目**：「即使……也……」是先說一個情況，再說結果還是不變。哪一句用得正確？

**正解**：即使下著大雨，哥哥也照常去練球。

**干擾項**

- 即使下著大雨，所以比賽暫停一次。　←　「即使」後面要接「也」，不能接說結果的「所以」。
- 因為下著大雨，哥哥也照常去練球。　←　前面用了「因為」，「下雨」和「照常練球」不是原因和結果的關係。
- 即使下著大雨，哥哥就留在家裡了。　←　「即使」要搭「也」，而且結果應該不受影響；留在家裡表示被雨影響了。

**提示**

1. 先找一找每一句有沒有用到「即使」和「也」這一組詞。
2. 「即使」後面說的是不好的情況，後面的結果會被它改變嗎？
3. 下大雨照理會讓人不想出門，哪一句的人還是照原來的樣子做？

**詳解**：正確概念：「即使……也……」先提出一個假設的情況，再用「也」說出結果不會因此改變。下大雨，哥哥還是照常練球，就是這種用法。

破誤：「即使下著大雨，所以比賽暫停一次。」：「即使」後面要接「也」，不能接說結果的「所以」。 「因為下著大雨，哥哥也照常去練球。」：前面用了「因為」，「下雨」和「照常練球」不是原因和結果的關係。 「即使下著大雨，哥哥就留在家裡了。」：「即使」要搭「也」，而且結果應該不受影響；留在家裡表示被雨影響了。

回頭讀：第二課語文練習「即使……也……」，看「狀況」和「結果」。

**驗證**：概念判斷題，請人工確認：課本 p.15 奶奶煮粥的一段「即使放涼了，也一樣美味無比」；p.19 語文練習「即使……也……」（假設複句）。選項為自編。

### L03-Q4　閱讀策略：六何法

**題目**：小真用六何法替課文提問：「五味屋是怎麼運作的？」這是六何裡的哪一種問題？

**正解**：如何：問事情怎麼做

**干擾項**

- 為何：問事情的原因　←　「為何」問為什麼；「怎麼運作」問的是做法。
- 何事：問發生什麼事　←　「何事」問發生了什麼；這題問的是運作的方法。
- 何人：問事情是誰做的　←　題目沒有問是誰，問的是怎麼做。

**提示**

1. 六何是：何人、何事、何時、何地、為何、如何。
2. 問句裡的關鍵詞是「怎麼」，它在問原因、人物，還是方法？
3. 「為什麼」和「怎麼做」是不一樣的問題，要分清楚。

**詳解**：正確概念：「怎麼運作」問的是方法和過程，屬於「如何」。六何法可以幫我們從人、事、時、地、原因、方法六方面提問，把內容想得更完整。

破誤：「為何：問事情的原因」：「為何」問為什麼；「怎麼運作」問的是做法。 「何事：問發生什麼事」：「何事」問發生了什麼；這題問的是運作的方法。 「何人：問事情是誰做的」：題目沒有問是誰，問的是怎麼做。

回頭讀：第三課語文練習「用六何法練習提問」。

**驗證**：概念判斷題，請人工確認：課本 p.25 語文練習「用六何法練習提問」（含「五味屋是如何運作？」等例）；語文天地一用六何法確認材料。

### L03-Q5　短文閱讀：名字的由來

**附件**
> 【短文】走出花蓮的豐田車站，就能看到一間蘋果綠的日式老房子，它叫五味屋。這間房子原本要被拆掉，一群熱心的人把它留了下來，整理成二手商店。店裡的店長是社區的孩子，大學生和志工在一旁陪伴。孩子們整理物品、打掃店面、招呼客人，嘗到了酸、甜、苦、辣、鹹各種滋味，「五味屋」的名字就是這樣來的。做完工作可以得到點數，存起來能換日用品，還能換到外地參加學習活動的機會。孩子們慢慢明白：靠自己的努力，也能為自己換來機會。

**題目**：根據上面的短文，「五味屋」這個名字是怎麼來的？

**正解**：孩子在店裡工作，嘗到各種人生滋味

**干擾項**

- 店裡專門賣五種不同口味的點心　←　短文寫五味屋是二手商店，沒有賣點心。
- 房子是五個熱心的人一起出力保下的　←　短文只說「一群熱心的人」，沒有說是五個人。
- 店裡每一樣東西都只賣五塊錢　←　短文沒有寫價錢，「五」不是指錢。

**提示**

1. 找一找短文裡哪裡出現「酸、甜、苦、辣、鹹」。
2. 這五個字是在說食物的味道，還是孩子做事時的感受？
3. 孩子當店長時遇到開心、辛苦的事，這些感受和店名有什麼關係？

**詳解**：正確概念：孩子在五味屋整理物品、清潔店面、招呼客人，體會到酸、甜、苦、辣、鹹的人生五味，這就是店名的由來。

破誤：「店裡專門賣五種不同口味的點心」：短文寫五味屋是二手商店，沒有賣點心。 「房子是五個熱心的人一起出力保下的」：短文只說「一群熱心的人」，沒有說是五個人。 「店裡每一樣東西都只賣五塊錢」：短文沒有寫價錢，「五」不是指錢。

回頭讀：第三課寫孩子當店長的那一段。

**驗證**：概念判斷題，請人工確認：自編短文中段；對應課本 p.22「體會酸、甜、苦、辣、鹹這人生五味，這也是這間店的名字──五味屋的由來」。

### L03-Q6　主旨與寓意

**題目**：讀完〈充滿希望的五味屋〉，哪一句最能說出這一課的重點？

**正解**：五味屋讓舊物再利用，也讓孩子學會獨立

**干擾項**

- 五味屋是花蓮最熱鬧、最好玩的景點　←　課文提到遊客會來，但重點不是介紹觀光景點。
- 老房子都應該拆掉，改建成新商店　←　課文正好相反，五味屋是把要拆的老房子留了下來。
- 孩子在店裡當店長，是為了幫自己家裡賺錢　←　孩子工作換的是點數和學習機會，不是替家裡賺錢。

**提示**

1. 五味屋賣的是什麼樣的東西？
2. 孩子在五味屋做了哪些事，學到了什麼？
3. 最後一段說孩子們「變得獨立，讓未來充滿希望」，把這和二手商品合起來想。

**詳解**：正確概念：五味屋保留老房子、販售二手商品，讓物品延續生命；也讓社區孩子在陪伴和工作中學習，變得獨立，對未來充滿希望。

破誤：「五味屋是花蓮最熱鬧、最好玩的景點」：課文提到遊客會來，但重點不是介紹觀光景點。 「老房子都應該拆掉，改建成新商店」：課文正好相反，五味屋是把要拆的老房子留了下來。 「孩子在店裡當店長，是為了幫自己家裡賺錢」：孩子工作換的是點數和學習機會，不是替家裡賺錢。

回頭讀：第三課最後一段。

**驗證**：概念判斷題，請人工確認：課本 p.20～23 全課；本課主旨：了解資源再生及老屋保存的意義，彰顯社區營造與在地人文關懷。

### L03-Q7　短文閱讀：推想學到的事

**附件**
> 【短文】走出花蓮的豐田車站，就能看到一間蘋果綠的日式老房子，它叫五味屋。這間房子原本要被拆掉，一群熱心的人把它留了下來，整理成二手商店。店裡的店長是社區的孩子，大學生和志工在一旁陪伴。孩子們整理物品、打掃店面、招呼客人，嘗到了酸、甜、苦、辣、鹹各種滋味，「五味屋」的名字就是這樣來的。做完工作可以得到點數，存起來能換日用品，還能換到外地參加學習活動的機會。孩子們慢慢明白：靠自己的努力，也能為自己換來機會。

**題目**：根據上面的短文，孩子們用工作換點數，最可能從中學到什麼？

**正解**：努力付出，就能替自己換到機會

**干擾項**

- 點數存得多，就可以不用上學　←　短文說點數能換學習活動的機會，不是不用上學。
- 二手的東西都比新東西好用　←　短文沒有比較新舊東西哪一個好用。
- 想買東西以前，要先向大人借錢　←　孩子是用自己工作換來的點數，不是向大人借錢。

**提示**

1. 找短文最後兩句，點數可以換什麼？
2. 點數是怎麼來的？是別人送的，還是自己做事得到的？
3. 把「做完工作」和「換到機會」連起來，孩子會怎麼想？

**詳解**：正確概念：孩子要先整理物品、招呼客人等完成工作才有點數，再用點數換日用品和學習機會，因此明白靠自己的努力就能得到機會。

破誤：「點數存得多，就可以不用上學」：短文說點數能換學習活動的機會，不是不用上學。 「二手的東西都比新東西好用」：短文沒有比較新舊東西哪一個好用。 「想買東西以前，要先向大人借錢」：孩子是用自己工作換來的點數，不是向大人借錢。

回頭讀：第三課讀「點數存摺」的部分。

**驗證**：概念判斷題，請人工確認：自編短文末段；對應課本 p.22～23「點數存摺」，讓孩子建立「靠自己努力獲得機會」的工作態度。
