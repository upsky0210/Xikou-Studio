### L06-Q1　缺水的線索

**題目**：盆栽好幾天沒澆水，葉片和枝條下垂。想先檢查是否和缺水有關，怎麼做最合適？

**正解**：補澆水後觀察葉片

**干擾項**

- 換到陰涼處觀察葉片　←　【變因混淆】把缺水的問題改成測光照
- 施肥後觀察枝條　←　【名詞混淆】把養分不足和缺水當成一樣
- 修剪後觀察剩下的葉片　←　【變因混淆】以為剪掉症狀就能知道原因

**提示**

1. 想想這幾天少了哪件照顧工作。
2. 要測試缺水，就從供水這個條件著手。
3. 比較補充前後的下垂情形，哪個做法能取得這項證據？

**詳解**：正確概念：補水後若葉片和枝條逐漸恢復，就支持缺水的猜想。換位置改變光照，施肥改變養分，剪葉則移除了要觀察的部位。

證據提示：課本第 34～35 頁，比較缺水下垂與澆水後恢復的盆栽。

**驗證**：概念判斷題，請人工確認：課本 p.34～35：比較缺水下垂與澆水後恢復的盆栽。

證據提示：課本第 35～38 頁，小百日草吸水活動和植物體內水分運輸圖。

### L06-Q7　根莖葉合作

**附件**
| 操作 | 觀察 |
|---|---|

**題目**：上表是小組對同一株植物的紀錄。哪個水分移動的次序最能同時解釋兩筆發現？

**干擾項**

- 土中的水 → 莖 → 根 → 葉 → 空氣　←　【次序顛倒】以為每個部位都能先吸收土裡的水
- 空氣中的水 → 葉 → 莖 → 根 → 土裡　←　【次序顛倒】把土中吸水和葉片蒸散整段倒過來
- 土中的水 → 根 → 葉 → 莖 → 空氣　←　【次序顛倒】忘了莖是根和葉之間的運輸通道

**提示**

1. 分別圈出兩筆紀錄涉及的部位。
2. 澆水後先經過土裡的部位，接著才到高處。

**詳解**：正確概念：水由根吸收，經莖送到葉，再由葉蒸散。莖在根之後、葉之前，水分由葉往空氣移動，因此其餘路線至少顛倒了一段。
